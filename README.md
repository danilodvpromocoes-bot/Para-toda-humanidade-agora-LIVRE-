# GOLDCOIN - RESERVA UNIVERSAL PARA POBRES.
### Dei pão aos homens. Agora deixo a reserva livre.

Eu dei pão aos homens quando tive pão.
Eu dei água quando tive água.
Mas eu vi que o homem continuava com fome.

Porque a fome do homem não é só de pão.
É de liberdade. É de valor. É de um futuro que não seja roubado quando ele dorme.

O sistema atual cria dinheiro do nada. Imprime infinito.
E quando se imprime infinito, o pão de quem trabalhou a vida inteira vale menos.

Por isso criei a GOLD RESERVE.

**0+0+1=1**

0 + 0 é o sistema. Vazio e ganancioso = NADA.
+1 é Deus. É a criação. É o sopro que transforma nada em algo.
1 é o resultado. É o valor que surge quando o homem encontra Deus
